# Code Buddies

Children learn computers and coding the fun way. **Robot Missions** (20 missions in 4 Nigerian worlds: Market Run, School Run, Farm Friends, Lagos Lights) teach steps in order, loops, decisions, functions and variables with picture blocks that turn into real Python. **Code Studio** lets children write Python that draws Adire patterns, tells talking stories and makes their own games (Catch the Mango, Penalty Kick), a market calculator and a number puzzle. **School ICT** has Primary 1 Computer Studies: 12 topics over three terms with read-aloud lessons, hands-on activities (mouse, keyboard, desktop and more), practice questions, term badges, a final challenge and a certificate. **Toddler Zone** (ages 2 to 4) has Robot Road and Find It! (computer things). Coding legends, a robot garage, badges, certificates and voice messages from parents.

Made by **Dr. Arowolo Ayoola**.

## Put it online with GitHub Pages (about 10 minutes, no coding)

1. **Sign in** at <https://github.com/login> as **AROWOLO-ABIMBOLA**.
2. **Create the repository:** open <https://github.com/new>, name it `codegame`, choose **Public**, tick **Add a README file**, and click **Create repository**.
3. **Upload the files:** open <https://github.com/AROWOLO-ABIMBOLA/codegame/upload/main>
   - Drag in **everything inside this folder**: `index.html`, `manifest.webmanifest`, `sw.js`, `README.md`, `.nojekyll` and the whole `icons` folder. (Replace the README if asked.)
   - Commit message: `Code Buddies first release`, then click **Commit changes**.
4. **Switch on GitHub Pages:** open <https://github.com/AROWOLO-ABIMBOLA/codegame/settings/pages>
   - **Source:** Deploy from a branch. **Branch:** `main`, folder `/ (root)`. Click **Save**.
5. **Wait 1 to 2 minutes.** Watch <https://github.com/AROWOLO-ABIMBOLA/codegame/actions> for a green tick, then open
   **https://arowolo-abimbola.github.io/codegame/**
6. **Share the link** on WhatsApp, by text or by email.

## Updating the game later
Open <https://github.com/AROWOLO-ABIMBOLA/codegame/upload/main>, drag in the new `index.html` (and `sw.js` when its version number changes) and commit. Children get the new version the next time they open the game with internet. Their progress is not affected.

## For parents: how it works

**Each child's progress is saved on the device they play on.** There are no accounts and nothing is sent to a server.

- **Install it like an app.** On Android (Chrome), tap **📲 Install app** on the home screen, or the browser menu **⋮ → Add to Home screen / Install app**. On iPhone or iPad (Safari), tap **Share**, then **Add to Home Screen**. The game then has its own icon and works without internet.
- **Please install it on iPhones and iPads.** Safari may clear website data if a site is not opened for 7 days. Games added to the Home Screen keep their progress.
- **Blocks or Python?** Children up to age 8 start with picture blocks; from age 9 they start with Python. Every block shows its Python twin, and the 🐍 button turns blocks into real Python. Change the starting style in **🔒 Parent corner → Settings**.
- **Real Python** (Code Studio, 🌐 button) loads the full Python language from the internet, about 10 MB the first time. Everything else works offline.
- **Several children on one device:** tap **👪** on the home screen to switch child or add a new one.
- **Moving to a new phone or keeping a safe copy:** **🔒 Parent corner → Settings → 💾 Save backup**, then **📂 Load backup** on the new device. Voice messages stay on the device where they were recorded.
